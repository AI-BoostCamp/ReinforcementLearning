1장은 강화학습으로 들어가기 전에 필요한 **Deep Learning 의 핵심 개념과 Keras 사용법**을
정리하는 장이다. 이 교재는 강화학습 교재이므로 **1장의 본문은 싣지 않고 목차만 남긴다.**
3장 이후의 실습은 Keras 로 Q-Network · Actor · Critic 을 만들기 때문에, Keras 모델
설계(`Sequential` · Functional API · Subclassing), `compile` / `fit` / `predict`, callback
정도는 알고 있다는 전제로 쓰였다. 낯설다면 강의의 1장 자료를 먼저 보는 것이 좋다.

**이 장의 구성** (강의 슬라이드 기준)

- **1.1 Deep Learning 개요** — Machine Learning 의 정의와 분류, Regression · Logistic
  Regression · Multi-class logistic regression, 계층적 표현 학습 개념, 역전파 학습과
  Vanishing Problem, Optimization Algorithm, Overfitting 과 Generalization.
- **1.2 Keras Model 설계 workflow** — Model Define API(Sequential · Functional · Subclassing),
  Model Compile API(Optimizer · Loss functions · Multi loss), Model Fit API(Training /
  Validation dataset · Epochs · Batch size), Evaluate · Predict API(Test dataset),
  Model Save API, Callback functions.
- **1.3 Keras.layers API** — Layers API, Activation function, Regularizer, Dropout,
  BatchNormalization, Convolution layer 와 CNN 모델 만들기(실습 1~5, 실습과제).

강의 원본에는 1장 실습 노트북 `1.2.1.ModelDesign.ipynb`, `1.2.2.callback.ipynb`,
`1.3.1.Layers.ipynb`, `1.3.2.ConvNet.ipynb` 가 함께 있다. 이 교재의 `code/` 에는 넣지 않았다.
