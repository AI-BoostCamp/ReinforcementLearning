4장의 여섯 절은 서로 다른 논문에서 왔지만, 되짚어 보면 **같은 세 질문에 대한 서로 다른 답**이다 —
target 을 무엇으로 삼는가, 정책을 얼마나 · 어떻게 움직이는가, 경험을 어떻게 모으고 쓰는가. 그리고 그 앞에
"시작하기 전에 무엇을 준비해야 하는가" 가 있다.

**시작하기 전에.** 4.1 절은 알고리즘이 아니라 태도를 다뤘다. 강화학습은 확률적 최적화라 본질적으로
비효율적이고, 그래서 **MDP 설계 — 특히 상태 $S$ 와 보상 $R$** — 가 프로젝트의 절반이다. 알고리즘은 문제의
markovian 성질(MC 와 TD)과 리턴의 변동성(value-based 와 policy gradient + baseline)으로 고르되, **hyper
parameter 가 알고리즘 선택만큼 중요**하고 결과는 재현이 어렵다. 공식 구현체와 baseline 을 확인하고, 환경
상호작용을 병렬화하고, 실험을 기록하고, 성능은 소수 실행의 중앙값이 아니라 신뢰구간과 함께 평가한다. 이
장의 실습마다 "3~5 번 반복해 변동성을 보라" 는 과제가 붙은 이유다.

**target 을 무엇으로 삼는가 — 과대평가와의 싸움.** 2.7 절에서 처음 본 Maximization bias 가 이 장의 절반을
끌고 간다. 4.2 절의 **DDQN** 은 DQN 의 target $r + \gamma \max_{a'} Q_t(s', a')$ 에서 **행동 선택은 online $Q$,
평가는 target $Q_t$** 로 분리해 — $r + \gamma Q_t(s', \arg\max_{a'} Q(s',a'))$ — 추가 network 없이 Double
Q-learning 의 효과를 얻었다. 행동 수가 늘수록 커지는 bias 가 Atari 에서 실제로 성능을 무너뜨린다는 것도
보았다. 4.3 절의 **TD3** 는 같은 문제를 Actor-Critic 에서 다룬다 — critic 을 둘 두고 **작은 쪽**을 target 으로
쓰는 Clipped Double Q, 가치 오류가 큰 동안 정책을 건드리지 않는 Delayed policy update, target 행동에 noise
를 더해 critic 을 매끈하게 하는 Target Policy Smoothing. ablation 표는 그중 Clipped Double Q 의 기여가 가장
크다고 말했다. 4.6 절의 **SAC** 도 두 critic 의 min 을 쓴다 — 여기에 entropy 항 $-\alpha \log \pi$ 가 더해져
target 이 $r + \gamma(\min Q' - \alpha \log \pi)$ 가 된다.

**정책을 얼마나 · 어떻게 움직이는가 — 안정성과의 싸움.** on-policy Actor-Critic 이 불안정한 근본 원인은
한 번의 표본으로 정책을 크게 밀 수 있다는 것이었다. 4.5 절의 **PPO** 는 정책의 변화율 $r_t(\theta) =
\pi_\theta / \pi_{\theta_{old}}$ 를 $[1-\epsilon, 1+\epsilon]$ 로 잘라 **한 batch 로 여러 번 갱신해도 정책이 멀리 가지
못하게** 했다(Clipped Surrogate Loss). TRPO 의 KL 제약을 loss 가 아니라 clip 과 early stopping 으로 바꾼
것이고, advantage 는 GAE 로 만들었다 — 2.5 절의 TD($\lambda$) 가 여기서 다시 나온다. TD3 의 Delayed policy
update 도 같은 정신이다 — 정책은 천천히.

**경험을 어떻게 모으고 쓰는가 — 상관성과 탐색.** DQN 계열은 replay buffer 로 상관성을 끊었지만 on-policy
방법은 그럴 수 없었다. 4.4 절의 **A3C** 는 buffer 대신 **여러 worker 를 비동기로** 돌려 서로 다른 에피소드의
경험이 섞이게 했다 — A2C + asynchronous method. 학습 시간이 thread 수에 비례해 줄고, 탐색이 저절로
다양해지며, entropy regularization 으로 정책이 너무 빨리 굳는 것을 막는다. 4.6 절의 **SAC** 는 탐색을
regularization 이 아니라 **목적 함수 자체**에 넣었다 — Maximum Entropy RL. 보상과 entropy 의 균형을
temperature $\alpha$ 로 조절하고(SAC-v2 는 $\alpha$ 도 학습한다), Squashed Gaussian 정책과 reparameterization
trick 으로 확률적 정책을 off-policy 로 학습한다. 그래서 SAC 는 stochastic policy optimization 과 DDPG-style
approach 의 중간에 서서, 고차원 연속 제어(Humanoid)에서 가장 강했다.

**한 줄로 잇는 계보.** 2.7 절 Q-Learning 의 $r + \gamma \max_{a'} Q(s', a')$ 에서 시작해 DQN 은 target 을 고정하고
경험을 재사용했고, DDQN 은 선택과 평가를 분리했고, DDPG 는 $\max$ 를 actor 로 바꿨고, TD3 는 두 critic 의
min 을 취했고, SAC 는 거기에 entropy 를 더했다. 정책 쪽은 REINFORCE → Actor-Critic → A2C → A3C → PPO 로
"덜 흔들리게, 더 많은 경험으로" 움직여 왔다. 부록 A 의 분류표(A.13)가 이 계보를 한 장에 그린다.

**스스로 점검할 것**

- Deep RL Project 를 시작하기 전에 준비할 다섯 가지: MDP 설계, 알고리즘 선택, hyper parameter 선택, 효율적 접근, 정보 관리.
- DDQN 이 DQN 의 Overestimation bias 를 어떻게 줄이는가 — target 식에서 무엇이 바뀌었는가.
- TD3 = DDPG + Clipped Double Q + Delayed policy update + Target Policy Smoothing. 각 장치가 푸는 문제.
- A3C = A2C + Asynchronous method. correlation 문제를 어떻게 풀고 학습 속도를 어떻게 얻는가.
- PPO 가 정책 함수 $\pi_\theta$ 를 천천히 바꾸는 방법 — Clipped Surrogate Loss 와 GAE.
- SAC = MaxEnt RL(Entropy-Regularized RL) + Q-function. Stochastic policy optimization 과 DDPG-style approaches 의 중간에 있다는 뜻.

이것으로 본문은 끝이다. 부록 A 에는 이 뒤에 나온 개선안(GRPO, Ape-X, Noisy Net, Rainbow)과 연구 흐름
(표현학습, 일반화, Offline RL, Multi-Task, Multi-Agent, Evolution Strategies), 그리고 전체 분류표를 모았다.
