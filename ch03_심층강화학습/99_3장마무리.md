# 3장을 마치며

3장은 2장의 표를 **함수**로 바꾸고, 그 함수를 **신경망**으로 두었다. 갱신식은 2장 것을 그대로 쓰되, 표의
한 칸을 고치는 대신 loss 를 정의하고 경사하강으로 파라미터를 움직인다. 여섯 절은 두 갈래 — **가치를
배우는 길**(3.1 → 3.3 → 3.4)과 **정책을 배우는 길**(3.5) — 을 각각 올라간 뒤, 3.6 절에서 둘을 합쳤다.

**함수 근사가 왜, 어떻게 가능한가.** 3.1 절은 Q-table 의 한계에서 출발했다. 상태가 연속이거나 너무 많으면
칸을 다 채울 수 없고, 채워도 방문하지 않은 칸은 배울 수 없다. 대신 $\hat{v}(s, w)$, $\hat{q}(s, a, w)$ 처럼
파라미터 $w$ 를 가진 함수를 두고, **target 은 2장에서 가져온다** — MC 의 $G_t$, TD 의 $r + \gamma \hat{v}(s', w)$,
Q-Learning 의 $r + \gamma \max_{a'} \hat{q}(s', a', w)$. target 과 현재 추정의 차이를 loss 로 삼으면 감독학습
과 같은 형태가 되고, 근사 함수의 형태(상태 → 가치, 상태·행동 → 가치, 상태 → 모든 행동의 가치)에 따라 신경망의
입출력이 정해진다. 3.2 절은 그 신경망의 최소 배경 — 회귀, 이항 · 다항 로지스틱 회귀, Softmax — 을 정리했다.
Softmax 출력이 곧 3.5 절의 확률적 정책이다.

**가치를 배우는 길.** 3.3 절의 **Naïve Deep Q-Learning** 은 2.7 절 Q-Learning 을 그대로 Q-Network 로 옮긴
것이다 — off-policy, 연속 상태 공간, target $r + \gamma \max_{a'} Q(s', a')$. CartPole 에서 돌아가긴 하지만
tuning 이 까다롭다. 이유는 두 가지였다. 연속된 경험이 서로 **상관**되어 있고, target 을 만드는 network 가
학습 중인 network 자신이라 target 이 **계속 움직인다**. 3.4 절의 **DQN** 은 이 둘을 각각 **Experience Replay**
(buffer 에서 무작위로 뽑아 상관을 끊는다 — off-policy 이기에 가능하다)와 **Target Network**(일정 주기로만
복사해 target 을 고정한다)로 풀었고, 이미지(sensory input)를 stacking 해 상태로 쓰는 법을 보였다. DQN 의
이 두 장치는 이후 DDPG · TD3 · SAC 가 모두 그대로 가져간다.

**정책을 배우는 길.** 3.5 절은 방향을 바꿨다. 가치를 거쳐 정책을 끌어내는 대신 **확률적 정책 $\pi_\theta(a \mid s)$
자체를 파라미터화**하고 목적 함수 $J(\theta)$ 를 직접 올린다. Policy Gradient Theorem 이 그 gradient 를
$\nabla_\theta \log \pi_\theta(a \mid s) \cdot Q^\pi(s,a)$ 의 기댓값으로 바꿔 주었고, $Q^\pi$ 자리를 무엇으로
채우느냐가 알고리즘을 갈랐다. **REINFORCE** 는 MC 리턴 $G_t$ 로 채운다 — on-policy 이고 에피소드 단위로
묶어 학습하며, 분산을 줄이기 위해 Baseline 과 Return Normalization 을 쓴다. **Actor-Critic** 은 $G_t$ 를
신경망(critic)으로 추정한다 — Q Actor-Critic, baseline 으로 $V$ 를 뺀 Advantage Actor-Critic(A2C), TD error 를
advantage 로 쓰는 TD Actor-Critic. 매 step 갱신할 수 있게 되었지만 여전히 on-policy 라 replay buffer 는 못
쓴다. 3.5.3 실습의 W&B 는 이런 실험들을 기록하는 습관을 붙이기 위한 것이었다.

**두 길이 만나는 곳.** 3.6 절의 **DDPG** 는 연속 행동 공간을 위해 정책을 결정적 함수 $\mu(s)$ 로 두고
(Deterministic Policy Gradient), critic 은 DQN 처럼 Experience Replay 와 Target Network 로 학습한다 —
DPG + Actor-Critic + Replay Memory + Target Net(soft update) 이라는 조합이다. 정책이 결정적이라 탐색은
행동에 noise(Ornstein-Uhlenbeck)를 더해 만든다. Pendulum 에서 동작하지만 hyper parameter 에 민감하다는
것도 함께 보았다 — 그 민감함이 4장의 출발점이다.

**스스로 점검할 것**

- 표 대신 $\hat{v}(s, w)$, $\hat{q}(s, a, w)$ 를 쓸 때 target 을 MC · TD · Q-Learning 에서 어떻게 가져오는가.
- Regression · Logistic regression · Softmax 가 가치 함수와 정책 함수의 출력층에 각각 어떻게 대응하는가.
- Naïve Deep Q-Learning 이 off-policy · 연속 상태 공간에서 Q-table 을 Q-Network 로 바꾼 방식과, 그것이 불안정한 두 이유.
- DQN 의 Sensory input, Experience replay, Target network 가 각각 어느 문제를 푸는가.
- REINFORCE(MC 로 $G_t$ 추정, on-policy, 에피소드 단위, Return Normalization)와 Actor-Critic(신경망으로 $G_t$ 추정,
  on-policy)의 차이, Q Actor-Critic · A2C · TD Actor-Critic 의 관계.
- DDPG 가 연속 행동 공간을 위해 DPG · Actor-Critic · Replay Memory · Target Net 을 어떻게 결합했는가.

다음 장은 여기서 만든 두 뼈대의 약점을 하나씩 고친다 — DQN 의 과대평가(DDQN), DDPG 의 불안정(TD3),
on-policy Actor-Critic 의 느린 학습과 상관성(A3C), 정책 갱신의 과격함(PPO), 탐색과 성능의 균형(SAC).
